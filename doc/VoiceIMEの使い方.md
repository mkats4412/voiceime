# VoiceIME（ボイスアイエムイー）使い方マニュアル

VoiceIME は、macOS 向けの超高速・高精度な音声入力＆AI対話アシスタントアプリです。  
メニューバーに常駐し、Whisper API（Groq / OpenAI 等）と各種 LLM（Gemini / Claude / GPT 等）を連携させて、日常のタイピングや文章作成を劇的に効率化します。

## 1. 基本の音声入力（Push-to-Talk）

### 🎤 操作方法（デフォルト: `Ctrl + Space`）
1. 入力したいアプリ（ブラウザ、Slack、メモ帳、ターミナルなど）の入力欄にカーソルを置きます。
2. **`Ctrl + Space` を押したまま** 話します。
3. 話している最中、フローティング画面に **リアルタイムで認識テキストが表示（紙芝居更新）** されます。
4. 話し終え、内容を目視確認したら **キーを離します**。
5. 最適な漢字変換・句読点補正（およびAI推敲）が行われ、**元の入力欄に自動ペースト** されます。

> [!TIP]
> **トグルモードへの切り替えも可能**  
> 設定画面の「ショートカット・音声設定」から「トグルモード（1回押して録音開始、もう1度押して停止）」に変更することもできます。

## 2. 神機能：＋キーによるピン留め・修正モード

「ちょっと言い間違えたから直したい」「長文をじっくり確認してから入力したい」という時に最適な機能です。

### ✍️ 使い方
1. `Ctrl + Space` を押して音声入力中、またはキーを離す直前に **テンキーやキーボードの `+`（プラス）キー** を押します。
2. キーを離してもフローティング画面が消えずに画面上に **ピン留め固定** されます。
3. 自動的に編集モードになり、**キーボードで文字を直接修正・追記** できます。
4. **`-`（マイナス）キーで差分を自動予測して単語登録（新機能！）**:
   - 文字を直した後に **`-` キー** を押すと、修正前後の差分（例: 「渋谷公会堂」➔「渋公」）から修正後の単語（`渋公`）を自動検出し、`vocabulary.json` に即座に **単語登録** されます。
   - 次回から Whisper がその単語を優先して認識するようになります。
5. 修正が終わったら：
   - **`⌘ + Enter`（または「挿入」ボタン）**: 直前に開いていたアプリにフォーカスが自動で戻り、修正済みテキストがそのままペーストされます。
   - **`+` キーをもう一度押す（または Esc）**: ウィンドウが閉じます（修正内容はクリップボードに退避・保持されるため安心です）。

### 📦 修正履歴の自動ストック & MCP連携
- 修正モードで編集した文章は、`~/.voiceime/corrections.json` に自動ストック保存されます。
- 後から Claude や Cursor 等の **AI Agent (MCP)** からこの修正履歴を参照し、未登録の単語や置換ルール（`dictionary.json`）をまとめて学習・登録させることができます。
- 設定画面の「単語登録・辞書」タブにある **「MCP連携 & AI Agent編集（修正ストック・単語登録）を有効にする」** トグルで ON/OFF を切り替えられます（※ 本来の推奨値はOFF、現在はテストのため初期値ON）。

> [!NOTE]
> フローティングウィンドウの上部をドラッグすることで、画面上の邪魔にならない好きな位置へ自由に移動できます。

## 3. AIクイック質問（対話モード）

文章の入力だけでなく、作業中にAIへちょっとした調べ物や質問ができます。

### 💡 操作方法（デフォルト: `Ctrl + Option + Space`）
1. **`Ctrl + Option + Space` を押したまま** 質問を話します（例：「粗大ゴミの英語は？」「お礼メールの締めくくりを考えて」）。
2. キーを離すと、即座に AI が回答を生成してフローティング画面に表示します。
3. 回答表示後の操作：
   - **`⌘ + Enter`**: 直前のアプリの入力欄へ回答文を直接挿入。
   - **「コピー」ボタン（クリック）**: 全文を一発でクリップボードにコピー（または `⌘ + A` で全選択後に `⌘ + C`）。
   - **`Esc`**: ウィンドウを閉じる。
   - **再度 `Ctrl + Option + Space`**: 前の会話の文脈を覚えたまま、続けて追加の質問ができます（連続会話）。

#### 📌 質問前の修正も可能！
質問を話している最中に **`+` キー** を押すと、AIへ送信する前に質問文を修正できます。`⌘ + Enter` を押すと修正後の質問が AI へ送信されます。

## 4. 音声で使える記号・コマンド（辞書機能）

発声するだけで、記号や改行をスムーズに入力できます。

| 発声する言葉 | 入力される記号 | 備考 |
|---|---|---|
| **改行** | `\n` | 次の行へ改行されます |
| **まる** | `。` | 句点 |
| **カンマ** | `、` | 読点 |
| **ピリオド** | `.` | 英文ピリオド |
| **クエッションマーク** | `？` | 疑問符（英語文脈では半角 `?`） |
| **びっくり** | `！` | 感嘆符（英語文脈では半角 `!`） |
| **ひらきかぎかっこ** / **とじかぎかっこ** | `「` / `」` | 鉤括弧 |
| **ひらきかっこ** / **とじかっこ** | `(` / `)` | 丸括弧 |
| **ひらきかくかっこ** / **とじかくかっこ** | `[` / `]` | 角括弧（ブラケット） |
| **ひらきなみかっこ** / **とじなみかっこ** | `{` / `}` | 波括弧（ブレース） |
| **ダブルクォート** / **シングルクォート** | `"` / `'` | 引用符 |
| **さんてんリーダー** | `…` | 三点リーダー |

> [!TIP]
> **ユーザー辞書の追加・カスタマイズ**  
> 設定画面の「単語登録・辞書」タブから、独自の言い回しや専門用語、記号置換ルールを自由に追加できます。  
> 辞書データは `~/.voiceime/dictionary.json` に保存され、エディタ等で直接編集しても自動同期されます。

## 5. AI推敲機能（口語モード / 文章モード）

Whisper が書き起こした生のテキストを、LLM が文脈に合わせて自動校正します。

- **推敲 OFF**: Whisper が書き起こした言葉を1文字も変えずにそのまま出力します（超高速）。
- **口語モード**: 話者のトーンや親しみやすい口語ニュアンス（「〜だよね」「〜してみて」等）を残したまま、同音異義語の漢字間違いや、早口で抜けた句読点を補正します。
- **文章モード**: ビジネスメールや日報、報告書に適した「です・ます」「である」調の端正で自然な文章に整えます。

設定画面の「プロンプト設定」から、推敲時のプロンプトを自分好みに自由にカスタマイズできます。

## 6. マイク感度としきい値（dB）の調整

エアコンの音やキーボードの打鍵音、周囲の環境ノイズを拾わないようにする重要な設定です。

1. メニューバーのアイコン ➔ **「設定」** ➔ **「ショートカット・音声設定」** を開きます。
2. **「マイクテスト」** を開始すると、リアルタイムの音量メーターが表示されます。
3. **無音時（話していない時）の音量レベルより少し高め**（例: `-38 dB` 〜 `-34 dB` 付近）にしきい値スライダーを合わせます。
4. これにより、声を出した時だけ的確に録音・送信され、沈黙中に無駄な通信が発生するのを完全に防止できます。

## 7. トラブルシューティング & ログ確認

### Q. 話した内容の最後（語尾）が切れてしまう
- 最新バージョンでは、発話末尾に息継ぎ（0.2秒程度の小休止）が入るか、キーを離した直後に自動的に最後の音声まで取り込むよう最適化されています。
- 早口になりすぎず、話し終わりに一呼吸置いてからキーを離してみてください。

### Q. 音声認識の経過やログを確認したい
- 設定画面の「ショートカット・音声設定」下部にある **「ログファイルを表示」** をクリックすると、ログファイル（`pipeline.log`）が開きます。
- ターミナルでリアルタイムに確認したい場合：
  ```bash
  tail -f ~/.voiceime/pipeline.log
  ```

## 8. ショートカットキー早見表

| ショートカット | 動作 | 対象・場面 |
|---|---|---|
| `Ctrl + Space`（長押し） | 音声入力開始（離すと入力） | 通常の文章入力 |
| `+`（プラスキー） | ピン留め・修正モードへ移行 | 音声入力中・確認中 |
| `-`（マイナスキー） | 修正差分から単語を自動予測して単語登録 | 修正モード中 |
| `⌘ + Enter` | 最前面アプリ（修正中にクリックした入力欄）へテキストを直接挿入 | 修正モード中・AI回答時 |
| `Ctrl + Option + Space` | AIクイック質問（対話） | AIへの質問・調べ物 |
| `⌘ + A` ➔ `⌘ + C` | 全選択してクリップボードにコピー（※画面の「コピー」ボタンならワンクリックで全文コピー） | 修正モード中・AI回答時 |
| `Esc` | フローティング画面を閉じる | 修正モード中・AI回答時 |
